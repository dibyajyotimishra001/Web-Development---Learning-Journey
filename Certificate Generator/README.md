# AI ML Certificate Generator

**Live Preview:** [https://raj-aiml-certificate.netlify.app/](https://raj-aiml-certificate.netlify.app/)

## Overview
The AI ML Certificate Generator is a lightweight, frontend web application that allows users to enter their details and instantly generate a customized completion certificate for Artificial Intelligence or Machine Learning courses.

## Features
* **Dynamic Generation:** Takes user inputs (name, joining year, completion year, course, and gender) via a clean form and displays them on a generated certificate using JavaScript and LocalStorage.
* **Fully Responsive:** Carefully styled with CSS media queries to ensure it works flawlessly across all devices, including desktops, tablets, and mobile phones.
* **Modern UI:** Features a dark-themed data entry form that transitions into a clean, printable certificate layout.

## Technologies Used
* HTML5
* CSS3 (Custom properties, Media Queries)
* Vanilla JavaScript (DOM Manipulation, LocalStorage)
* Bootstrap 5 (Icons and basic resets via CDN)

## How to Run Locally
1. Clone or download the repository.
2. Ensure the folder structure is intact (with `index.html` at the root and `certificate.html`, `script.js`, and `style2.css` inside the `page` directory).
3. Open `index.html` in any modern web browser to use the application.
