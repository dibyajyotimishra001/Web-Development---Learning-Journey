# My BookMarks - Python Courses

## Description
A clean, responsive web page designed to store and display bookmarked Python course videos from YouTube. This project serves as a personal video library, allowing easy access to educational content in a structured layout.

## Features
* **Modern Dark Theme:** Implements a sleek dark background (rgb(49, 49, 49)) with light text, providing a comfortable and modern viewing experience.
* **Responsive Design:** Utilizes CSS media queries (max-width: 1091px) to ensure the layout adapts seamlessly to different screen sizes. On smaller screens, the video grid transforms into a centered, single-column layout with dynamically resizing iframes (75vw).
* **Flexbox Layout:** Uses CSS Flexbox for aligning and distributing the embedded videos efficiently.
* **Polished UI:** Includes customized structural elements such as rounded corners on video iframes (border-radius: 20px) and a distinct header background color (rgb(39, 15, 58)).

## Technologies Used
* HTML5
* CSS3
