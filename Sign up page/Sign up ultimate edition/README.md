# Sign Up Form

A simple, modern, and responsive Sign Up form built using HTML and CSS.

## Live Demo

Try the project here: https://ai-heist.netlify.app/

## Features

- Modern dark-themed user interface
- Fully responsive design for desktop, tablet, and mobile devices
- Input fields for:
  - Name
  - Password
  - Email
  - Review
- Gender selection using radio buttons
- "Remember Me" checkbox
- Styled submit button
- Clean and organized layout
- Easy to customize and beginner-friendly

## Technologies Used

- HTML5
- CSS3

## How to Use

1. Download or clone the project.
2. Open `index.html` in your web browser.
3. Fill in the form and interact with the interface.

---

This project was created to practice HTML forms, CSS styling, and responsive web design.
