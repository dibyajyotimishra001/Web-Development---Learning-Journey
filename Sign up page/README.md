# Themescore - Sign-Up Page

## Overview
This project is a responsive, modern sign-up page developed as part of a continuous web development learning journey. It features a clean user interface with essential form elements and responsive design principles, ensuring compatibility across desktop and mobile devices.

## Features
* **User Registration Form:** Includes input fields for Username, Password, Confirm Password, Email, Date of Birth, and Gender selection.
* **Responsive Layout:** Automatically adapts to various screen sizes, including phones and tablets, utilizing CSS media queries.
* **Modern UI/UX:** Styled with custom CSS, featuring a centralized container layout, contrasting color scheme, and interactive hover states.
* **Input Validation:** Utilizes built-in HTML5 validation attributes for required fields and proper data formatting.

## Technologies Used
* HTML5
* CSS3

## File Structure
* `sign-up.html`: Contains the core structural markup of the application.
* `style.css`: Contains all styling rules, layout constraints, and responsive breakpoints.

## Setup Instructions
1. Download or extract the project files into a local directory.
2. Open the `sign-up.html` file in any modern web browser (e.g., Brave, Chrome, Firefox).
3. No external dependencies, server setups, or build steps are required to view the frontend interface.
