# Responsive User Login Form

This project features a modern, beautifully designed, and fully responsive user input form built strictly using HTML5 and CSS3. It is designed to capture user details like Name, City, and Pin-Code.

## Key Features

* **Flexbox Architecture:** Utilizes CSS Flexbox (`display: flex`, `flex-direction: column`) to perfectly align the labels and input fields vertically.
* **Perfect Centering:** Uses `min-height: 100vh` to horizontally and vertically center the form container on the viewport without using absolute positioning hacks.
* **Fully Responsive:** Implements media queries (`@media (max-width: 1144px)`) to ensure the layout adapts flawlessly across desktop, tablet (iPad), and mobile screens, reducing the container width to maintain margins.
* **Modern UI Design:** Features a clean aesthetic with a dark purple background, a floating white container with box shadows, rounded corners, and smooth hover effects on the submit button.
* **Form Validation:** Includes HTML attributes like `autofocus` for immediate user engagement and `required` to prevent empty submissions.

## Technologies Used

* HTML5
* CSS3 (Flexbox, Media Queries, Box Model)

## How to View

Simply download or clone the repository and open the `index.html` file in any modern web browser to see the responsive layout in action. Resize the browser window to see how it adapts to different screen sizes.
